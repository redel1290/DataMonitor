# Data Monitor — моніторинг трафіку

Android-додаток (Kotlin, Jetpack Compose, min SDK 31), який показує
постійне (динамічне) сповіщення з використанням трафіку за сьогодні
(00:00–зараз) окремо для Wi-Fi та мобільної мережі (2G/3G/4G/5G),
а для мобільної мережі — ще й скільки ГБ приблизно залишилось у тарифі.

## Як це працює

- **Foreground-сервіс** (`DataMonitorService`) кожні ~20 секунд і при
  кожній зміні мережі оновлює одне й те саме сповіщення (id незмінний —
  тому воно "живе", а не спамить новими).
- Використання рахується через `NetworkStatsManager` (Usage Access —
  потрібно один раз дати дозвіл вручну, Android це вимагає).
- **Ліміт мобільних ГБ**: Android не дає жодного публічного API, щоб
  дізнатись баланс/дату поповнення тарифу в оператора — це закрита
  інформація самого оператора. Тому в додатку так:
  1. При старті додаток намагається (best-effort) прочитати дані з SIM
     через `TelephonyManager` — на практиці це майже завжди нічого не
     дає (система це блокує для звичайних застосунків).
  2. Якщо авто-визначення не вдалось — з'являється сповіщення/екран з
     поясненням, і два поля для ручного вводу:
     - **Загальний обсяг у тарифі (ГБ)** — стабільне значення на
       випадок нового поповнення.
     - **Скільки зараз залишилось (ГБ)** — від цього числа додаток
       щодня віднімає використане і показує залишок у сповіщенні.
  3. Кнопка **"Поповнення (скинути ліміт)"** — вручну скидає залишок
     назад до загального обсягу (натискаєш після того, як оператор
     поповнив пакет).
- **Порогові сповіщення**: окремі поля для Wi-Fi та мобільної мережі —
  скільки МБ за сьогодні має бути використано, щоб прийшло окреме
  сповіщення-попередження (наприклад, 300 МБ для мобільної).

## Збірка через GitHub Actions

У репозиторії вже є `.github/workflows/build.yml` — при кожному push
у `main` (або вручну через "Run workflow") збирається debug APK і
кладеться в Artifacts збірки.

### Команди для першого пушу в GitHub

```bash
# 1. Розпакуй архів проєкту і перейди в папку
cd DataMonitor

# 2. Ініціалізуй git (якщо ще не ініціалізовано)
git init
git branch -M main

# 3. Додай усі файли і зроби перший коміт
git add .
git commit -m "Initial commit: Data Monitor app"

# 4. Створи порожній репозиторій на GitHub (через сайт або gh CLI)
gh repo create your-username/DataMonitor --public --source=. --remote=origin
# або, якщо репозиторій вже створений на GitHub вручну:
git remote add origin https://github.com/your-username/DataMonitor.git

# 5. Запуш код — це автоматично запустить Actions-збірку
git push -u origin main
```

### Отримати готовий APK

1. Відкрий репозиторій на GitHub → вкладка **Actions**.
2. Вибери останній запуск workflow **"Build APK"**.
3. Внизу сторінки, розділ **Artifacts** → завантаж `DataMonitor-debug-apk.zip`.
4. Розпакуй, всередині буде `app-debug.apk` — став на телефон.

### Наступні коміти

```bash
git add .
git commit -m "опис змін"
git push
```

Кожен push у `main` автоматично перезбере APK.

## Дозволи, які додаток попросить на телефоні

- **Доступ до статистики використання** (Usage Access) — відкриється
  системний екран, потрібно знайти "Data Monitor" і увімкнути вручну
  (Android не дозволяє запитати це звичайним діалогом).
- **Сповіщення** (Android 13+) — стандартний діалог.
- **Телефон / стан мережі** (`READ_PHONE_STATE`) — потрібен, щоб
  визначати саме 2G/3G/4G/5G, а не просто "мобільна мережа".

## Обмеження

- Дані про використання після перезавантаження пристрою можуть на
  короткий час "зʼїхати" — це особливість `NetworkStatsManager`,
  не додатку.
- Точний баланс/дата поповнення тарифу — недоступні через API, тому
  завжди вводяться вручну (пояснено вище).
